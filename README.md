# A* Pathfinding Visualizer

## Project Overview
An interactive application that visualizes the A* pathfinding algorithm on a grid to find a path between a start point and a destination while avoiding obstacles.

## Features
- Interactive grid with start and end point selection
- Obstacle placement and removal
- Step-by-step visualization of the A* algorithm
- Visual representation of explored nodes and the final path
- Grid reset functionality

## Technologies
- Python
- Pygame
- Priority Queue and basic data structures
